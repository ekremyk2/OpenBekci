# Adding a translatable string

Turkish and English are first-class; every user-facing string needs both.

## Server

- Notifications: add the type to `server/internal/core/notifications/locales/en.json` and `tr.json` (title, body, subject, sms).
- Labels for enums and error codes: add a `{en, tr}` pair in `server/internal/core/codes/codes.go`.
- Documents: `trMsgs` and `enMsgs` in `server/internal/core/governance/document.go`.
- Pack labels: `labelsEN` and `labelsTR` in the pack's `catalog.go`.

`go test ./...` fails when a key exists in one language only or is empty.

## Web

Wrap text in `<Trans>` or use `t` from Lingui, then run `pnpm i18n:extract` and fill the empty `msgstr` in `web/src/locales/tr/messages.po`. `pnpm lint` fails on bare JSX text (`openbekci/no-untranslated-text`).

## Mobile

Add the key to `lib/l10n/app_en.arb` (with `@key` description) and `app_tr.arb`, run `flutter gen-l10n`, use `AppLocalizations.of(context)`. CI runs `tool/ci/check_l10n.sh`: missing keys, a stale `lib/l10n/gen`, or a hard-coded label fail the build.
