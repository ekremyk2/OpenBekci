# Security audit, November 2026 (pre-1.0)

Scope: `server/`, `sdk/`, `packs/*`, `web/` at `main` (5b0fc81). Method: read-first code review plus
targeted handler/unit tests for each fix. No PostgreSQL was available to the auditor, so the
integration suites (authz matrix, RLS, enumeration) were reviewed, not re-run; CI runs them.

## Findings

| # | Severity | Area | Finding | Status |
|---|----------|------|---------|--------|
| 1 | High | Headers | The server sent no CSP, HSTS, frame, referrer or nosniff headers with the embedded web bundle or the API (only file downloads had `sandbox`). The nonce CSP promised in the plan was never implemented. | Fixed: `securityHeaders` middleware (`httpapi/middleware.go`); test `TestSecurityHeadersOnWebAndAPI`. CSP is `script-src 'self'` (no inline script exists; `theme-init.js` is same-origin). |
| 2 | High | Input (XLSX) | The core bank importer (`bankimport/parse.go`) and the TR pack bank formats (`packs/tr/statement.go`) opened workbooks with excelize defaults (16 GiB unzip limit), so a 10 MiB upload could inflate into memory (zip bomb). The people importer already had caps. | Fixed: 64 MiB total / 32 MiB per XML part in both; tests `TestReadXLSXRefusesZipBomb` (core and pack). |
| 3 | Medium | Input | Bank statement import caps bytes (10 MiB) but not line count; a 10 MiB CSV of short rows can insert millions of lines. | Open. Add a row cap like `people.MaxImportRows`. |
| 4 | Medium | Headers | CSP allows `style-src 'unsafe-inline'` (UI components set inline styles). `index.html` carries an unused `__CSP_NONCE__` placeholder. | Open. Move to a per-response nonce when the web build stops using inline styles. |
| 5 | Low | Dependencies | `govulncheck`: GO-2026-5932 (`x/crypto/openpgp`), module required but package not called; fix exists only as a pseudo-version. `pnpm audit --prod`: no known vulnerabilities. | Open (unreachable). Bump `x/crypto` when a tagged release ships. |
| 6 | Low | Auth | Session cookie has no `__Host-` prefix (it is `HttpOnly`, `Secure`, `SameSite=Lax`, Path `/`). | Open. |
| 7 | Low | SSRF | Push relay enrollment (`platform/push/enroll.go`) posts to the instance-admin-configured relay URL without the private-range guard used for sending. Instance admin only; redirects are refused. | Open. |
| 8 | Low | Output | Pack Markdown templates receive resident-supplied text unescaped; the result is typeset to PDF (formatting injection only, no HTML or script path). | Open. |
| 9 | Info | Tenancy | Platform-pool (BYPASSRLS) use is limited to pre-tenant lookups (API key and agent token by prefix, org listing for jobs, prune). Sampled, not exhaustively verified per query. | Open (review item). |

## Checked, no finding

- RLS: `TestIntegrationRLS...` iterates every `public` table; only the documented exempt list is skipped, and pack migrations refuse an `org_id` table without RLS (`packs/migrate.go`). Exempt tables are instance-wide identity or delivery tables.
- Authz: `TestAuthzMatrixRowsCoverSpec` fails if any spec operation lacks a matrix row, any org operation lacks `x-openbekci-roles`, or a row is stale (coverage equals served operation count). API keys: refused on operations naming no permission, cannot manage keys or webhooks, scopes intersect the creator's current grants, cannot carry occupancy grants.
- Auth: 256-bit opaque tokens stored as SHA-256; refresh reuse revokes the family; lockout runs under an advisory lock; CSRF needs Origin plus `X-Requested-With` for cookie mutations; `Authorization` bearer is not CSRF-exposed.
- Input: image header check before decode, storage keys validated (no `..`), signed URLs HMAC with constant-time compare, `mime.FormatMediaType` for filenames, mail via go-mail (header encoding).
- Money: DB `CHECK (amount > 0)` on payments and outflows, overflow-checked `Money`, provider webhooks verified by signature and re-fetched, checkout targets taken from the stored checkout.
- Jobs: River jobs have bounded `MaxAttempts` (8 for webhooks and notifications, library default otherwise); webhook jobs are unique by args.
- Audit log: `REVOKE` plus `BEFORE UPDATE/DELETE/TRUNCATE` triggers on `audit_event` and `platform_audit_event`.
- Secrets: `_FILE` variants for all secret settings; pack `x-secret` fields; request logger never logs query, headers or bodies.
